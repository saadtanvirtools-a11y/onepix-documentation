About Content 2

The About Content 2 section is a visual highlight section for the About page. It uses a background image with a dark overlay and shows three content cards, each with its own icon, title, and text settings.

How to Add About Content 2

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the About page template in the Theme Editor.

Step 4: Select About Content 2 from the left sidebar.

Step 5: Update the background image, overlay, and the three content cards from the right-side settings panel.

Section Settings

The main section controls for About Content 2 are shown below.

  • Background image: Upload or replace the section background image.
  • Dark overlay opacity: Control the overlay strength placed above the background image.
  • Card 1 icon class: Add the icon class used for the first card.
  • Card 1 custom SVG: Paste a custom SVG if you want to replace the icon class.
  • Card 1 title: Edit the first card title.
  • Card 1 text: Edit the first card descriptive text.
  • Card 2 icon class: Add the icon class used for the second card.
  • Card 2 custom SVG: Paste a custom SVG if needed.
  • Card 2 title: Edit the second card title.
  • Card 2 text: Edit the second card descriptive text.
  • Card 3 icon class: Add the icon class used for the third card.
  • Card 3 custom SVG: Paste a custom SVG if needed.
  • Card 3 title: Edit the third card title.
  • Card 3 text: Edit the third card descriptive text.

Card & Style Settings

The lower settings area also includes appearance options for the section.

  • Fallback background color: Set a backup background color for the section.
  • Text color: Set the color used for the card content.
  • Custom CSS: Add section-specific custom CSS when needed.
  • Remove section: Remove the section if it is no longer needed.
