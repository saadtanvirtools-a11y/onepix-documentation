Related Products

The Related Products section uses Shopify's Product recommendations feature to show products that may be relevant to the product a customer is currently viewing. The recommendations are dynamic and can change over time based on product and order information.

How to Add Related Products

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open Products from the template selector and choose the product template you want to edit.

Step 4: Select the existing Product recommendations section, or click Add section and add it to the product template.

Step 5: Configure the heading, product count, responsive columns, product-card settings, colors, and spacing from the right settings panel.

Section Settings

Select Product recommendations in the left sidebar to edit the related-products section. Shopify notes that these recommendations are dynamic and use order and product information to improve over time.

  • Layout: Choose the overall width style for the section, such as Container.
  • Heading: Edit the section heading, such as You May Also Like.
  • Heading tag: Choose the heading HTML tag, such as H2.
  • Heading size: Set the visual size of the heading.
  • Heading alignment: Align the heading to the Left, Center, or Right.
  • Product count: Set the maximum number of recommended products displayed.
  • Columns desktop: Set how many product cards appear per row on desktop.
  • Columns tablet: Set the number of product cards shown per row on tablet.
  • Columns mobile: Choose 1 column or 2 columns on mobile.
  • Gutter: Adjust the spacing between product cards.

Product Card Settings

The Product card controls change how each recommended product is displayed inside the section.

  • Image ratio: Set the aspect ratio used for product images, such as 1:1.
  • Media focal point: Choose the focal point used when product media is cropped.
  • Quick add: Enable or disable quick-add functionality for recommended products.

Colors, Spacing & Custom Settings

  • Text: Set the text color used in the section.
  • Background: Set the section background color.
  • Background gradient: Apply a gradient background if needed.
  • Top margin: Adjust the outer spacing above the section.
  • Bottom margin: Adjust the outer spacing below the section.
  • Top padding: Adjust the inner top spacing.
  • Bottom padding: Adjust the inner bottom spacing.
  • Custom ID: Add a custom HTML ID to the section.
  • Custom classes: Add custom CSS class names.
  • Custom CSS: Add CSS that applies only to this section.
The products in this section are recommendations generated by Shopify. The Theme Editor settings shown here control the section layout and appearance rather than manually choosing each recommended product.
