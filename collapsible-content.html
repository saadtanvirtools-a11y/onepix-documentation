Collapsible Content

The Collapsible Content section creates an FAQ-style accordion on the storefront. It lets you add a preheading, heading, optional image, colors and spacing, then build the accordion by adding multiple Collapsible row blocks.

How to Add Collapsible Content

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the page where you want to use the section.

Step 4: Click Add section and select Collapsible content.

Step 5: Use Add Collapsible row in the left sidebar whenever you want to add another accordion row.

Section Settings

Select the main Collapsible content section to edit its overall appearance and heading area.

  • Image: Add an optional image to the section.
  • Preheading: Add the small label shown above the main heading, such as FAQs.
  • Heading: Set the main section heading, such as You Asked, We Answered.
  • Subheading: Add optional supporting text below the heading.
  • Heading size: Choose the display size of the main heading.
  • Heading tag: Choose the HTML heading tag, such as H2.
  • Heading alignment: Align the heading to the left, center, or right.
  • Use custom colors: Enable custom colors for this section.
  • Label color: Set the preheading color.
  • Heading color: Set the main heading color.
  • Text: Set the accordion text color.
  • Background: Set the section background color.
  • Background gradient: Add a gradient background if required.
  • Top margin: Control the outside spacing above the section.
  • Bottom margin: Control the outside spacing below the section.
  • Top padding: Control the inner spacing above the section content.
  • Bottom padding: Control the inner spacing below the section content.

Adding Collapsible Rows

From the left sidebar, click Add Collapsible row to create a new accordion item. You can add multiple rows, so the section can contain several FAQ questions or information panels.

Each Collapsible row is edited separately. Click any row in the left sidebar to change only that row without affecting the other rows.

Collapsible Row Settings

  • Heading: Set the title or question shown on the collapsed row.
  • Collapsible row: Add the text that appears when the row is opened.
  • Row content from page: Select page content to use inside the row when needed.
  • Remove block: Remove that individual collapsible row.
To create a full FAQ section, keep using Add Collapsible row. Then click each row individually to edit its heading and expanded content.
