Mega Menu - Products

Use Mega Menu - Products when you want the dropdown to show selected products, selected collections, or both. This is useful for top-level menu items such as Catalog.

How to Add Mega Menu - Products

✓

Step 1: Go to Online Store → Themes → Customize.

Step 2: Open the Header section and add or select the Mega Menu - Products block.

Step 3: In For item, choose the top-level menu item, such as Catalog.

Step 4: Set the Wrapper dropdown width and Dropdowns per row.

Step 5: Turn on Enable product list to select products, or turn on Enable collection list to select collections.

Step 6: Optionally enable HTML code when you want extra custom content inside the dropdown.

Products and Collections Options

The Mega Menu - Products block supports both product-based and collection-based dropdown content.

  • Enable product list: Turns on a selected list of products in the mega menu.
  • Products: Choose the products you want to display.
  • Enable collection list: Turns on a selected list of collections.
  • Collections: Choose the collections you want to display, such as Face Wash, Moisturizers, and Serums.
  • Enable HTML code: Adds an optional custom HTML area.

Mega Menu - Products Settings

  • For item: The top-level menu item that opens this mega menu.
  • Wrapper dropdown width: Controls the dropdown width.
  • Dropdowns per row: Sets how many product/collection groups appear per row.
  • Top padding / Bottom padding: Adjusts the inner spacing.
  • HTML code: Lets you include additional custom content when enabled.
You can use products, collections, or both in the same Mega Menu - Products block depending on how you want the dropdown to look.
