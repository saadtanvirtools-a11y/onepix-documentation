Rich Text

The Rich Text section is a flexible content section for presenting a preheading, heading, supporting text, and call-to-action button. It can be used for brand introductions, promotions, announcements, product highlights, or other text-focused content.

How to Add Rich Text

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the page where you want to display the content.

Step 4: Click Add section and select Rich text.

Step 5: Select the new Rich text section in the left sidebar and configure its content, button, alignment, colors, and spacing.

Content and Layout Settings

Select the Rich text section to edit the content displayed inside it.

  • Layout: Choose the section width, such as Container.
  • Wide display content: Enable a wider content presentation when needed.
  • Style: Choose between the available Style 1 and Style 2 layouts.
  • Preheading: Add a small label above the main heading, such as “New in”.
  • Heading: Enter and format the main heading text.
  • Heading tag: Choose the HTML heading tag, such as H2.
  • Heading size: Select the visual size of the heading, such as Extra large.
  • Subheading: Add and format the supporting text shown below the heading.
  • Button label: Set the text displayed inside the call-to-action button.
  • Link: Choose the page, product, collection, or other destination opened by the button.
  • Button style: Select the button style, such as Primary.
  • Desktop content alignment: Align the content left, center, or right on desktop.
  • Mobile content alignment: Align the content left, center, or right on mobile devices.

Colors and Spacing

Scroll further down in the Rich text settings to customize colors, margins, padding, and custom attributes.

  • Use custom colors: Enable section-specific colors.
  • Label color: Set the preheading or label color.
  • Heading color: Set the main heading color.
  • Text color: Set the supporting text color.
  • Background: Set the section background color.
  • Background gradient: Apply a gradient background if required.
  • Top margin: Adjust the outer spacing above the section.
  • Bottom margin: Adjust the outer spacing below the section.
  • Top padding: Adjust the inner spacing above the content.
  • Bottom padding: Adjust the inner spacing below the content.
  • Custom ID: Add a custom HTML ID to the section.
  • Custom classes: Add custom CSS class names.
  • Custom CSS: Add CSS that applies only to this section.
  • Remove section: Remove the Rich Text section from the page.
Use Rich Text when the focus is primarily on text and a call-to-action. The section can be added wherever the Theme Editor allows sections, so it is not limited to one specific page.
