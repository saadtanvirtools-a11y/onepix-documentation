Blog

The Blog documentation covers how to create a blog post in Shopify Admin and how that post is displayed and customized with the Default blog post template in the Onepix Theme Editor. The main Blog post section is block-based, so the title area, featured image, content, and tags can be selected and managed separately. You can also use Add section to place other supported theme sections on the blog post page.

Create a Blog Post in Shopify Admin

Create the post content in Shopify Admin first. The Theme Editor controls the layout and presentation of that content.

✓

Step 1: From Shopify Admin, go to Content → Blog posts.

Step 2: Click Add blog post.

Step 3: Enter the post Title and write the main Content.

Step 4: Add an Excerpt if you want a short summary of the post.

Step 5: Under Image, click Add image to upload the featured image used by the blog post.

Step 6: In Organization, choose the author and blog, then add any tags you want to use.

Step 7: Set the post Visibility as required.

Step 8: Under Theme template, select Default blog post.

Step 9: Click Save.

Open the Blog Post in the Theme Editor

✓

Step 1: Go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: From the page/template selector at the top, open Default blog post.

Step 4: In the left sidebar, select Blog post to edit the main blog post section.

Step 5: Save after you finish configuring the section and blocks.

Blog Post Blocks

The Blog post section uses individual blocks. Click a block in the left sidebar to edit its own settings. You can also click Add block when the section supports another block.

  • Title: Controls the post title area and optional post metadata/share options.
  • Featured image: Displays the image assigned to the blog post in Shopify Admin.
  • Content: Displays the main blog post content created in Shopify Admin.
  • Tags: Displays the tags assigned to the post in Shopify Admin.

Title Block

Select Title to configure the title area independently. The available controls shown in the Theme Editor include:

  • Show Excerpt: Show or hide the blog post excerpt.
  • Show date: Show or hide the post date.
  • Show author: Show or hide the post author.
  • Enable share: Show or hide the share control.
  • Title share: Change the text used for the share label.
  • Heading alignment: Align the title area left, center, or right.
  • Top margin / Bottom margin: Adjust spacing around this block.

Content Block

Select Content to manage the blog content block separately. The text itself comes from the blog post content entered in Shopify Admin. The block also provides its own top and bottom margin controls in the Theme Editor.

Tags Block

Select Tags to manage the tags area separately. The displayed tag labels come from the tags assigned to the blog post in Shopify Admin. The Tags block has its own top and bottom margin controls.

Add More Sections to the Blog Post Page

The blog post template is not limited to the main Blog post section. Click Add section in the left sidebar and choose any supported theme section you want to add to the page. The Theme Editor shown here already includes examples such as Marquee and Featured product, and you can add or remove sections according to your store design.

Blog post content such as the title, featured image, body content, and tags is created in Shopify Admin. The Theme Editor is used to control how those elements are displayed and to add extra theme sections around them.
