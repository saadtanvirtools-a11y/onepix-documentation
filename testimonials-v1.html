Homepage Sections

Testimonials v1

The Testimonials v1 section is used to display customer reviews in a clean testimonial slider layout. It helps you build trust by showing customer feedback, review text, rating, and customer names inside a carousel-style section.

How to Add Testimonials v1

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the Home page template in the Theme Editor.

Step 4: Click Add section and select Testimonials v1.

Step 5: Use the section settings on the right side, and use Add block from the left panel to add testimonial slides.

Section Settings

Select the Testimonials v1 section in the left sidebar to manage the main section styling and layout.

  • Heading: Add or edit the main section heading.
  • Heading size: Choose the heading size, such as Double Extra Large.
  • Heading alignment: Align the heading to the Left, Center, or Right.
  • Label color: Set the color of the small label text.
  • Heading color: Set the color of the main heading.
  • Background color: Choose the background color for the section.
  • Background gradient: Add a background gradient if needed.
  • Top margin: Control the outer spacing above the section.
  • Bottom margin: Control the outer spacing below the section.
  • Top padding: Control the inner spacing above the content.
  • Bottom padding: Control the inner spacing below the content.
  • Custom CSS: Add custom CSS specifically for this section.
  • Remove section: Remove the section from the page if you no longer need it.

Testimonial Blocks

This section also supports blocks. From the left sidebar, you can click Add block and add a Testimonials Carousel block. Each block represents an individual testimonial slide inside the carousel.

Use separate testimonial blocks to add multiple customer reviews. This makes it easy to manage each testimonial one by one.
  • Add block: Add more testimonial items to the carousel.
  • Testimonials Carousel: Edit each testimonial slide separately from the left sidebar.
  • Slider navigation: The section displays previous and next arrows for moving through testimonial slides.

Best Use

Use Testimonials v1 to highlight customer satisfaction, product results, and social proof. Keep the review text short and clear so the section remains easy to read.
