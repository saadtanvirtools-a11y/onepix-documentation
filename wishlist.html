Wishlist

The Wishlist page displays products that customers have saved to their wishlist. In Onepix, the page uses the wishlist page template and the Wishlist Page section. You can control the wishlist grid layout from the Theme Editor, and you can also use Add section to place other supported theme sections above or below the wishlist.

Create the Wishlist Page First

Before customizing the Wishlist layout in the Theme Editor, create the page in Shopify Admin and assign the wishlist template.

✓

Step 1: From Shopify Admin, go to Online Store → Pages.

Step 2: Create a new page, or open the page you want to use for the wishlist.

Step 3: Enter a page title such as Wishlist.

Step 4: In the Template panel on the right, open the dropdown and select wishlist.

Step 5: Set the page visibility as required and click Save.

Open Wishlist in the Theme Editor

✓

Step 1: Go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Use the page/template selector at the top of the Theme Editor and open the wishlist page.

Step 4: In the left sidebar, select Wishlist Page.

Step 5: Adjust the grid layout settings in the right sidebar, then save your changes.

Wishlist Page Settings

Select Wishlist Page in the left sidebar to configure how saved products are displayed.

  • Layout: Choose the overall section width, such as Container.
  • Columns desktop: Set how many wishlist product cards appear per row on desktop.
  • Columns tablet: Set the number of columns used on tablet screens.
  • Columns mobile: Choose a one-column or two-column layout for mobile.
  • Gutter: Adjust the spacing between wishlist product cards.
  • Custom CSS: Add section-specific CSS when you need additional styling.

The products shown inside this section come from the customer's saved wishlist. The product cards display the product image and product information, together with the wishlist control and a button for opening the product.

Add More Sections to the Wishlist Page

You can add other supported theme sections to the Wishlist page. In the left sidebar, click Add section, select the section you want, and then configure it normally.

The screenshot shows an About Hero Banner above the Wishlist Page section as an example. Extra sections are optional, so you can add only the content that fits your store.
