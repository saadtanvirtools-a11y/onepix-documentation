Header & Footer

Footer

The Footer section controls the bottom area of the storefront. You can edit the overall footer content, turn utility items on or off, and build the layout with separate Menu, Text, and Image blocks.

How to Add the Footer

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the Footer group in the theme editor.

Step 4: Select the Footer section to edit the section settings.

Step 5: Click Add block whenever you want to insert another footer block.

Footer Settings

Select the main Footer section to control the overall footer layout, text, utilities, and colors.

  • Heading: Add the main footer heading if required.
  • Subheading: Add supporting footer text or a short brand description.
  • Footer menu columns: Set the number of menu columns used inside the footer.
  • Social media icons: Show or hide the social icons row.
  • Payment method icons: Show or hide the payment icons at the bottom.
  • Policy links: Show or hide links such as policies managed in Shopify.
  • Copyright: Edit the copyright text shown in the footer bottom bar.
  • Use custom colors: Enable custom colors for the footer section.
  • Text: Set the footer text color.
  • Background: Set the footer background color.
  • Background gradient: Apply a gradient background when needed.
  • Border color: Control the footer divider or border color.
  • Top margin: Adjust the outer top spacing.
  • Bottom margin: Adjust the outer bottom spacing.
  • Top padding: Adjust the inner top spacing.
  • Bottom padding: Adjust the inner bottom spacing.
  • Custom attributes: Add custom attributes if required.
  • Custom CSS: Add footer-specific CSS.

Adding Footer Blocks

The footer also supports blocks. From the left sidebar, click Add block to insert a new block into the footer area.

As shown in the editor, you can add these block types:

  • Menu: Add a menu column such as Quick Links or Company.
  • Text: Add extra footer text content.
  • Image: Add an image block to the footer.

Each block can be edited separately after it is added. For example, you can click an individual Menu block in the sidebar and update only that footer menu without changing the other blocks.

Use Add block whenever you want more footer content. After adding a block, click that block in the left sidebar to edit it separately.
