Blog Posts v0

The Blog Posts v0 section lets you display articles from a selected Shopify blog directly on a product template. You can control the heading content, number of posts, article details, responsive columns, colors, spacing, and button options from the Theme Editor.

How to Add Blog Posts v0

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the required product template in the Theme Editor.

Step 4: Click Add section and select Blog posts v0.

Step 5: Select the section from the left sidebar and configure its blog, content, layout, and styling settings.

Blog & Content Settings

Select Blog posts v0 in the left sidebar to edit the section. The upper settings include:

  • Blog: Choose the Shopify blog whose articles should appear in the section.
  • Preheading: Add optional small text above the main heading.
  • Heading: Edit the section heading, such as NEWS.
  • Subheading: Add optional supporting text below the heading.
  • Heading size: Choose the visual size of the heading.
  • Heading tag: Choose the semantic HTML heading tag, such as H2.
  • Heading alignment: Align the heading left, center, or right.
  • Image ratio: Control the aspect ratio used for article images.
  • Posts: Set how many blog posts are displayed.
  • Show date: Show or hide each article's publication date.
  • Show excerpt: Show or hide the article excerpt.
  • Show comment: Show or hide comment information.
  • Show read more: Show or hide the Read more link.
  • Show 'View all' button: Show or hide the button linking to the full blog.
  • Button style: Choose the style used for the optional View all button.

Layout Settings

Use the layout controls to determine how many article cards appear across different screen sizes.

  • Columns desktop: Set the number of article columns on desktop.
  • Columns tablet: Set the number of article columns on tablet.
  • Columns mobile: Choose one or two columns for mobile devices.
  • Gutter: Control the spacing between article cards.

Colors, Spacing & Custom Settings

  • Use custom colors: Enable section-specific colors.
  • Text: Set the section text color.
  • Background: Set the section background color.
  • Background gradient: Apply a gradient background when needed.
  • Top margin: Adjust the outer spacing above the section.
  • Bottom margin: Adjust the outer spacing below the section.
  • Top padding: Adjust the inner spacing above the section content.
  • Bottom padding: Adjust the inner spacing below the section content.
  • Custom ID: Add a custom HTML ID.
  • Custom classes: Add one or more custom CSS classes.
  • Custom CSS: Add CSS that applies specifically to this section.
  • Remove section: Remove Blog posts v0 from the product template.
The section displays posts from the blog selected in the Blog setting. Article titles, dates, excerpts, and images come from your Shopify blog content.
