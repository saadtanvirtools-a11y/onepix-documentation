Homepage Sections

Content Block 3

The Content Block 3 section is a flexible collage-style homepage section that combines a large text area with a group of images. It is useful for inspiration content, blog promotion, lifestyle storytelling, or featured editorial content.

How to Add Content Block 3

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the Home page template in the Theme Editor.

Step 4: Click Add section and select Content Block 3.

Step 5: After adding the section, use Add block from the left sidebar to add and edit the inner content blocks separately.

Section Settings

Select the Content Block 3 section itself to control the main layout and section-level settings.

  • Layout: Choose the overall section width style, such as Container.
  • Main large image: Upload the main large image shown in the collage area.
  • Image link: Add a link to the main large image.
  • Use custom colors: Enable custom colors for this section.
  • Heading color: Set the heading color.
  • Text color: Set the text color.
  • Background color: Set the background color of the section.
  • Background gradient: Apply a gradient background if needed.
  • Margin top: Adjust the outer top spacing.
  • Margin bottom: Adjust the outer bottom spacing.
  • Padding top: Adjust the inner top spacing.
  • Padding bottom: Adjust the inner bottom spacing.
  • Custom ID: Add a custom HTML ID.
  • Custom class: Add a custom CSS class name.
  • Custom CSS: Add section-specific custom CSS.

Adding Blocks

Inside Content Block 3, you can click Add block from the left panel. Each block can be edited separately. In the example shown, the section uses blocks such as Heading, Text, Button, and multiple Collage image blocks.

This means when you click on a text block, you edit only that text content, and when you click on an image block, you can change only that image.

Heading Block

When you click the Heading block in the left sidebar, you can edit the section heading separately.

  • Heading: Add or change the heading text.
  • Heading tag: Choose the heading tag, such as H2 or H3.
  • Heading size: Select the heading size, such as Large, Medium, or Small.
  • Remove block: Remove the heading block if you do not need it.

Text Block

When you click the Text block, you can update the descriptive paragraph separately from the heading and other content.

  • Text: Add or edit the paragraph content.
  • Formatting toolbar: Use the editor options to style the text.
  • Remove block: Remove the text block if needed.

Collage Image Block

When you click a Collage image block, you can change that individual collage image separately. This allows you to build a custom image collage by adding multiple image blocks.

  • Image: Upload or replace the selected collage image.
  • Remove block: Remove that collage image block.

You can add multiple Collage image blocks from the left sidebar and manage each one individually.

Button Block

The section can also include a Button block for the main call to action, such as Visit Our Blog. Add or edit this block from the left sidebar to control the button content and link separately from the other blocks.
