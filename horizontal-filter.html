Collection Pages

Horizontal Filter

The Horizontal Filter collection layout displays the available product filters in a horizontal row above the product grid. Customers can open individual filter dropdowns such as Availability, Price, Color, Category, Product Type, Fragrance Level, and Brand without opening a separate drawer.

How to Apply This Collection Template

Before customizing the Horizontal Filter layout in the Theme Editor, assign its collection template to the collection you want to use.

✓

Step 1: From your Shopify Admin, go to Products → Collections.

Step 2: Create a new collection or open an existing collection, then add the products you want to show in that collection.

Step 3: Scroll down on the collection page until you find the Theme template option.

Step 4: Open the Theme template dropdown and select filter-horizontal.

Step 5: Click Save to apply the selected collection template.

The same process is used for all Onepix collection templates. Choose the required template from the dropdown, save the collection, and then open that template in the Theme Editor to customize its Product grid and any additional sections.

How to Open the Horizontal Filter Template

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the collection template selector and choose filter-horizontal.

Step 4: Select Product grid from the left sidebar.

Step 5: Under Filtering and sorting, set Filter layout to Horizontal.

How the Horizontal Filter Works

With this layout, the filter controls stay visible directly above the product grid. Each filter appears as a dropdown in the horizontal filter row, allowing customers to refine the collection without opening a separate filter drawer.

For this template, use Filter layout → Horizontal. The available storefront filters are displayed in a horizontal row above the products.

Product Grid Settings

Select Product grid to configure the collection layout and product-grid behavior.

  • Layout: Choose the overall content width, such as Container.
  • Products per page: Set how many products appear on each collection page.
  • Columns desktop: Set the number of product columns on desktop.
  • Columns tablet: Set the number of product columns on tablet.
  • Columns mobile: Set the number of product columns on mobile.
  • Gutter: Adjust spacing between product cards.
  • Pagination: Choose the loading method, such as Click to load.

Product Card Settings

  • Image ratio: Control the product-card image aspect ratio.
  • Quick add: Enable or disable quick purchasing controls.
  • Show border: Show or hide the product-card border.
  • Border color: Set the product-card border color.
  • Border radius: Adjust the product-card corner radius.
  • Border width: Control the border thickness.
  • Border style: Choose a border style such as Solid.

Filtering and Sorting

  • Enable collections list: Show or hide the collection-list filtering area.
  • Collections list: Choose which collections are included when the collection list is enabled.
  • Filters: Enable storefront product filters. The available filters are configured through Shopify's Search & Discovery app.
  • Filter layout: Set this to Horizontal for the Horizontal Filter template.
  • Sorting: Enable or disable the collection sorting control.

Spacing and Custom Settings

  • Margin top: Adjust the outer spacing above the section.
  • Margin bottom: Adjust the outer spacing below the section.
  • Padding top: Adjust the inner top spacing.
  • Padding bottom: Adjust the inner bottom spacing.
  • Custom ID: Add a custom HTML ID to the section.
  • Custom classes: Add custom CSS class names.
  • Theme Settings: Open the shared theme controls when required.
  • Custom CSS: Add CSS that applies only to this section.

Add More Sections

You can also add more sections to the filter-horizontal collection template. Click Add section in the left sidebar and choose any supported section you want to place above or below the Product grid.
