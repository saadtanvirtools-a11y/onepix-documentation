Onepix Shopify Theme
Theme Settings

Cart

The Cart settings control cart-note availability and the free-shipping message, threshold, completion message, and progress-bar colors.

How to Configure Cart

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: In the Theme Editor, open Theme settings.

Step 4: Open Cart.

Step 5: Configure the settings shown below and save your changes.

Cart Settings

  • Cart note: Enable or disable the cart note option.
  • Free shipping minimum amount: Set the amount required to reach the free-shipping goal.
  • Description - Goal completed: Edit the free-shipping progress message. The screenshot uses the [remaining_amount] placeholder in the message.
  • Post-Goal Message: Set the message displayed after the free-shipping goal is reached.
  • Progress Bar Full Color: Set the progress-bar color when the goal is complete.
  • Progress Bar Text Color: Set the progress-bar text color.
