Contact

The Contact page gives customers a dedicated place to view your store information and send a message. In Onepix, the page uses the contact template and the Contact form section, which can contain separately editable Information and Form blocks. You can also add other supported sections to the page from the Theme Editor.

Create the Contact Page First

Before customizing the Contact page in the Theme Editor, create the page in Shopify Admin and assign the contact template.

✓

Step 1: From Shopify Admin, go to Online Store → Pages.

Step 2: Create a new page, or open the page you want to use as your contact page.

Step 3: Enter a page title such as Contact.

Step 4: In the Template panel on the right, open the template dropdown and select contact.

Step 5: Set the page visibility as required and click Save.

Open the Contact Page in the Theme Editor

✓

Step 1: Go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Use the page/template selector at the top of the Theme Editor and open the contact page.

Step 4: In the left sidebar, select Contact form to edit the main contact section.

Step 5: Use the blocks inside the section to edit the information area and the customer message form separately.

Contact Form Section

Select Contact form in the left sidebar to configure the overall contact section. The section contains separate blocks that can be selected and edited independently.

  • Add block: Add another supported block to the Contact form section.
  • Information: Controls the store-information column shown on the left.
  • Form: Controls the customer message form shown on the right.
  • Heading size: Adjust the main heading size used by the section.
  • Gutter: Adjust the spacing between the section columns.
  • Custom CSS: Add CSS that applies only to this section.

Information Block

Click the Information block in the left sidebar to edit the contact details separately from the form.

  • Heading: Set the information-column heading, such as Information.
  • Subheading: Add supporting text below the heading.
  • Content: Add the phone number, email address, opening hours, address, or other store details. The rich-text field can contain formatted text and links.
  • Text color: Set the text color for the information block.
  • Vertical alignment: Position the block content at the top, middle, or bottom of its column.

Form Block

Click the Form block to edit the customer message area independently.

  • Heading: Set the form heading, such as Send Us A Message.
  • Subheading: Add optional supporting text above the form fields.
  • Use custom colors: Enable block-specific colors for the form area.
  • Text: Set the form text color.
  • Background: Choose the form-block background color.
  • Background gradient: Apply an optional gradient background.
  • Border color: Set the border color used by the form area and controls.

Add Other Sections to the Contact Page

The Contact page is not limited to the Contact form section. Click Add section in the left sidebar and choose any supported section you want to add to the page. You can place additional content above or below the Contact form and then configure that section normally.

For example, the Theme Editor screenshot shows an About Hero Banner above the Contact form and an Icon with text section below it. These are optional; use whichever sections fit your store.
