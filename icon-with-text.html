Icon With Text

The Icon With Text section displays a row or grid of feature cards with an icon, heading, and supporting text. It is useful for highlighting store benefits such as customer service, free shipping, returns, secure payments, or other key information.

How to Add Icon With Text

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the page where you want to show the feature cards.

Step 4: Click Add section and select Icon with text.

Step 5: Select the new Icon with text section in the left sidebar and configure its layout, colors, columns, and spacing.

Section Settings

Select the Icon with text section itself to control the overall appearance and layout.

  • Layout: Choose the section width, such as Full width.
  • Heading: Add an optional heading above the icon cards.
  • Heading tag: Choose the HTML heading tag, such as H2.
  • Heading size: Select the visual size of the section heading.
  • Heading alignment: Align the heading left, center, or right.
  • Columns desktop: Set how many cards appear per row on desktop.
  • Columns tablet: Set the tablet column count.
  • Columns mobile: Choose one or two columns on mobile.
  • Gutter: Adjust the spacing between cards.

Colors and Spacing

  • Use custom colors: Enable section-specific colors.
  • Heading color: Set the section heading color.
  • Text color: Set the card text color.
  • Icon color: Set the icon color.
  • Background color: Choose the section background color.
  • Background gradient: Apply a gradient if required.
  • Margin top / bottom: Control the outer spacing around the section.
  • Padding top / bottom: Control the inner spacing above and below the cards.
  • Custom ID: Add a custom HTML ID when needed.
  • Custom class / Custom CSS: Use the available custom fields for section-specific styling.

Add and Edit Card Icons

You can add multiple Card icon blocks inside the section. Each card can be edited independently, so every icon, heading, supporting text, and link can be different.

✓

Step 1: Expand the Icon with text section in the left sidebar.

Step 2: Click Add Card icon to add another feature card.

Step 3: Select any existing Card icon block to edit that specific card.

Card Icon Block Settings

  • Bootstrap icon class: Enter a Bootstrap icon class, such as bi bi-headset.
  • Enable custom SVG: Turn this on when you want to use your own SVG icon.
  • Custom SVG: Paste the SVG code when custom SVG is enabled.
  • Image: Select an image if you want to use an image instead of an icon class.
  • Heading: Enter the card title, such as Customer service.
  • Subheading: Add supporting text such as contact information, delivery details, or return information.
  • Button link: Add an optional destination so the card can link to another page.
Each Card icon block can be edited separately. Use Add Card icon whenever you want to add another feature to the section.
