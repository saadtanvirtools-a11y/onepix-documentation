Announcement Bar

The Announcement Bar lets you display promotional messages at the top of your storefront. You can add multiple Announcement blocks, and each block can be edited separately for its text, subtext, link, spacing, typography, and colors.

How to Add the Announcement Bar

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the Header group in the Theme Editor.

Step 4: Open Announcement bar, then click Add block to insert a new announcement.

Step 5: Click any Announcement block in the left sidebar to edit it separately.

Announcement Block Settings

Select an Announcement block to edit the content and styling for that specific bar message.

  • Text: Add the main announcement text.
  • Subtext: Add supporting text for the announcement message.
  • Button link: Choose where the announcement should link when clicked.
  • Text size: Control the size of the announcement text.
  • Top padding: Adjust the inner top spacing of the announcement bar.
  • Bottom padding: Adjust the inner bottom spacing of the announcement bar.
  • Use custom colors: Enable custom colors for this announcement block.
  • Text: Set the text color.
  • Background: Set the background color.
  • Background gradient: Apply a gradient background if needed.
  • Remove block: Remove the selected announcement block.

Managing Announcement Blocks

The announcement bar supports blocks, so you can add more than one message. Click Add block in the left sidebar to create another announcement row.

  • Add block: Adds a new announcement block.
  • Edit separately: Click any announcement block from the sidebar to update only that block.
  • Multiple promotions: Use separate blocks for shipping offers, discount messages, or campaign notices.
If you want multiple promotional messages, add multiple Announcement blocks and edit each one separately.
