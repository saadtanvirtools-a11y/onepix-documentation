Mega Menu - Text

Use Mega Menu - Text when you want a large text-based dropdown under a top-level navigation item such as Shop. First build the menu structure in Shopify Admin, then choose that item inside the Header block settings.

Add Menu Items in Shopify Admin

✓

Step 1: Go to Content → Menus → Main menu.

Step 2: Open the top-level item you want to use, for example Shop.

Step 3: Add grouped child links below it, such as Shop layouts, Product Layouts, Collections, and Explore More.

Step 4: Add the related links under each group so the mega menu can display them in columns.

Step 5: Click Save in Shopify Admin.

Edit the Block in Theme Editor

After the menu structure is ready, open the theme editor and select the Mega Menu - Text block under the Header.

✓

Step 1: Go to Online Store → Themes → Customize.

Step 2: Open the Header section and add or select the Mega Menu - Text block.

Step 3: In For item, enter the matching top-level menu item, such as Shop.

Step 4: Adjust the Wrapper dropdown width, Columns, and Mega menu spacing.

Mega Menu - Text Settings

  • For item: The top-level menu item that will trigger this mega menu.
  • Wrapper dropdown width: Controls how wide the dropdown is.
  • Columns: Sets the number of text columns displayed.
  • Top padding / Bottom padding: Adjusts the spacing inside the mega menu.
Edit the actual links and menu hierarchy from Content → Menus. Use the Mega Menu - Text block only to select the parent item and control the dropdown layout.
