Collection List Page

The Collection List Page displays your store collections in a configurable grid. You can show all collections or choose selected collections, control card titles and responsive columns, and add more sections to the page from the Theme Editor.

Create the Collection Page First

Before opening the Collection List layout in the Theme Editor, create the page in Shopify Admin and assign the collection template.

✓

Step 1: From your Shopify Admin, go to Online Store → Pages.

Step 2: Create a new page, or open the page you want to use for the collection list.

Step 3: Enter the page title, such as Collection.

Step 4: In the Template panel on the right, open the template dropdown and select collection.

Step 5: Set the page visibility as required and click Save.

How to Open the Collection List Page

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the page/template selector at the top of the Theme Editor and choose Collection list.

Step 4: In the left sidebar, select Collections list page.

Step 5: Configure the collection display, card settings, responsive columns, spacing, and any additional sections you want to use.

Collection List Settings

Select Collections list page in the left sidebar to edit the main collection-list section.

  • Layout: Choose the section width style, such as Container.
  • Background card: Set the background color used by collection cards.
  • Preheading: Add optional text above the main heading.
  • Heading: Set the main collection-list heading.
  • Subheading: Add supporting rich text below the heading.
  • Heading size: Choose the heading display size.
  • Heading tag: Choose the HTML heading tag, such as H1.
  • Heading alignment: Align the heading left, center, or right.

Choose Which Collections to Show

The section can display every collection or only collections you choose.

  • All: Display all available collections automatically.
  • Selected: Display only the collection entries you add to the section.
  • Add Collection: Use Add Collection in the left sidebar to add another collection entry when you are building a selected collection list.
  • Collection blocks: Existing collection entries appear under the section in the left sidebar so you can select and manage them separately.
The Theme Editor itself notes that all collections are listed by default. To customize the list, choose Selected and add the collections you want to display.

Card Settings

  • Title size: Set the display size of each collection-card title.
  • Title tag: Choose the HTML heading tag used for collection-card titles, such as H2.

Layout and Spacing

  • Columns desktop: Set the number of collection cards per row on desktop.
  • Columns tablet: Set the tablet column count independently.
  • Columns mobile: Set the mobile column count independently.
  • Gutter: Adjust spacing between collection cards.
  • Margin top: Adjust the outer spacing above the section.
  • Margin bottom: Adjust the outer spacing below the section.
  • Padding top: Adjust the inner top spacing.
  • Padding bottom: Adjust the inner bottom spacing.
  • Custom CSS: Add section-specific CSS when needed.

Add More Sections

You can add more sections to the Collection list page. Click Add section in the left sidebar and choose any supported section you want to place above or below the collection list.
