Homepage Sections

Marquee

The Marquee section displays a horizontally scrolling text strip that is useful for promotions, announcements, offers, shipping messages, or brand highlights. In the example shown, the marquee repeats the message “20% OFF YOUR NEXT ORDER” across the homepage.

How to Add Marquee

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the Home page template in the Theme Editor.

Step 4: Click Add section and select Marquee.

Step 5: Inside the section, click Add Marquee from the left panel to add scrolling text items.

Section Settings

Select the Marquee section in the editor to control the speed, direction, typography, colors, spacing, and custom attributes.

  • Time: Controls the scroll duration or movement speed of the marquee text.
  • Reverse: Reverses the scrolling direction.
  • Font size: Choose the text size for the marquee content, such as Smallest.
  • Use custom colors: Enable this option to apply custom text and background colors.
  • Text: Sets the marquee text color.
  • Background: Sets the background color of the marquee bar.
  • Background gradient: Apply a gradient background if needed.
  • Top margin: Adjust the outer spacing above the section.
  • Bottom margin: Adjust the outer spacing below the section.
  • Top padding: Adjust the inner spacing above the marquee content.
  • Bottom padding: Adjust the inner spacing below the marquee content.
  • Custom ID: Add a custom HTML ID for linking or section targeting.
  • Custom classes: Add one or more custom CSS class names.
  • Custom CSS: Add section-specific custom CSS if required.

Adding Marquee Items

From the left sidebar, click Add Marquee to insert more scrolling text blocks. Each block becomes part of the marquee sequence, allowing you to repeat the same message or show multiple different promotional messages.

This is useful when you want to display content such as discount offers, free shipping notices, limited-time announcements, or brand statements in a moving strip.

For the cleanest look, keep marquee text short and easy to read, especially when using smaller font sizes and faster scrolling speed.
