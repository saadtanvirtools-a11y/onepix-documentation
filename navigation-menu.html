How to Add Navigation Menu

Create and organize the storefront navigation from Shopify Admin. The menu you build here can then be selected from the Header → Menu setting in the theme editor.

How to Add a Navigation Menu

✓

Step 1: From Shopify Admin, go to Content → Menus.

Step 2: Open Main menu, or open the menu you want to edit.

Step 3: Click Add menu item to add a new navigation link.

Step 4: Add the menu item name and destination, then organize the items in the order you want them to appear.

Step 5: To create dropdown navigation, place related menu items underneath a parent menu item. The example shows nested items under Shop and Pages.

Step 6: Click Save after finishing your navigation structure.

Menu Structure

The menu can contain both top-level links and nested links. In the example, Home and Catalog are top-level items, while Shop and Pages contain nested menu items.

  • Top-level item: Appears directly in the main navigation.
  • Nested item: Appears under its parent item as dropdown navigation.
  • Add menu item: Adds another link to the menu.
  • Reorder: Arrange menu items in the order you want customers to see them.

Use the Menu in the Header

After saving the menu, open Online Store → Themes → Customize → Header. In the Header settings, use the Menu selector to choose the navigation menu you created.

If you change menu items later in Content → Menus, the Header will use the updated menu structure after the changes are saved.
