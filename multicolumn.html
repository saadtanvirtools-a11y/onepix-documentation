Sections

Multicolumn

The Multicolumn section lets you display multiple content cards in one row or grid. Each column can contain an image or video, heading, text, button label, and link, making this section useful for promotions, brand highlights, services, or featured content blocks.

How to Add Multicolumn

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the page where you want to place this section.

Step 4: Click Add section and choose Multicolumn.

Step 5: Select the section to edit its layout, heading, columns, colors, spacing, and other options.

Section Settings

Select the Multicolumn section itself to control the overall section layout and styling.

  • Layout: Choose the section width such as Container.
  • Preheading: Add a small text label above the main heading.
  • Heading: Enter the main section title.
  • Heading tag: Choose the heading HTML tag, such as H2.
  • Heading size: Select the visual size of the section heading.
  • Heading alignment: Align the main heading left, center, or right.
  • Media width: Control the image width inside each column.
  • Height: Set how the media height behaves, such as Adapt to media.
  • Content alignment: Align the content inside the columns.
  • Title size: Choose the size of each column title.
  • Title tag: Select the HTML tag used for each column title.
  • Columns desktop: Set how many columns appear in one row on desktop.
  • Columns tablet: Set the tablet column count.
  • Gutter: Adjust spacing between the columns.

Colors, Spacing, and Custom Fields

  • Use custom colors: Enable section-specific colors.
  • Heading color: Set the main heading color.
  • Text color: Set the text color used in the columns.
  • Background: Choose the section background color.
  • Background gradient: Apply a gradient background if needed.
  • Top margin / Bottom margin: Control the outer spacing around the section.
  • Top padding / Bottom padding: Control the inner spacing inside the section.
  • Custom ID: Add a custom HTML ID when required.
  • Custom classes: Add extra classes for custom styling.
  • Custom CSS: Apply section-specific custom CSS when needed.

Add and Edit Columns

You can add multiple Column blocks inside the Multicolumn section. Each column can be edited separately, so every card can have different content.

✓

Step 1: Expand the Multicolumn section in the left sidebar.

Step 2: Click Add Column to insert a new column block.

Step 3: Click any existing Column block to edit its content.

Column Block Settings

  • Image: Select an image for the column.
  • Video: Select a video if you want to use video content instead of or along with an image.
  • Preheading: Add optional small text above the column heading.
  • Heading: Enter the title for that specific column.
  • Subheading: Add the descriptive text for the column.
  • Button label: Set the button text such as Buy it now.
  • Link: Choose the destination for the button or card action.
Each Column block is editable separately, so you can create different cards inside the same Multicolumn section.
