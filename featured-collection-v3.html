Featured Collection V3

The Featured Collection V3 section lets you display products from a selected Shopify collection directly on the homepage. It is useful for highlighting best sellers, new arrivals, or any featured product group with optional add-to-cart support and a view-all button.

How to Add Featured Collection V3

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the Home page template in the Theme Editor.

Step 4: Click Add section and select Featured Collection V3.

Step 5: Choose the collection and configure the product display settings from the right-side panel.

Section Settings

Select the Featured Collection V3 section in the left panel to manage the settings shown in your screenshots.

  • Layout: Choose the section width style, such as Container.
  • Preheading: Add a small label shown above the main heading, such as Customer Favorites.
  • Label color: Set the color of the preheading text.
  • Heading: Add the main heading for the product section.
  • Heading tag: Choose the heading HTML tag, such as H2.
  • Heading size: Set the heading size, such as Large.
  • Subheading: Add supporting descriptive text below the heading area.
  • Collection: Choose which Shopify collection to display in this section.
  • Products to show: Set how many products from the selected collection appear.
  • Show view all button: Enable or disable the button that links visitors to the full collection page.
  • Button label: Change the text shown on the view-all button, such as Shop All.
  • Button link: Select the destination link for the button.
  • Enable add to cart: Turn on add-to-cart buttons directly within the product grid.
  • Use custom colors: Enable custom color styling for the section.
  • Text color: Set the section text color.
  • Background color: Set the section background color.
  • Background gradient: Add a gradient background if required.
  • Margin top: Control the space above the section.
  • Margin bottom: Control the space below the section.
  • Padding top: Adjust the inner top spacing of the section.
  • Padding bottom: Adjust the inner bottom spacing of the section.
  • Custom ID: Add a custom HTML ID.
  • Custom class: Add a custom CSS class name.
  • Custom CSS: Add custom CSS specifically for this section.

Product Display

This section automatically pulls products from the selected collection and displays them in a homepage product grid. You can control how many products are shown and whether customers can use Add to Cart directly from this section.

Use this section to highlight a curated collection such as best sellers, skincare, or seasonal products. Keep the heading short and use a clean background color to help the products stand out.
