FAQs

The FAQs page uses the faqs page template and one or more Collapsible content sections. Each Collapsible content section can contain multiple Collapsible row blocks, so you can organize questions into groups such as Products, Shipping, Returns, or any other category. Every row can be edited separately.

Create the FAQs Page First

Before editing the FAQ layout in the Theme Editor, create the page in Shopify Admin and assign the faqs template.

✓

Step 1: From Shopify Admin, go to Online Store → Pages.

Step 2: Create a new page, or open the page you want to use for FAQs.

Step 3: Enter a page title such as FAQs.

Step 4: In the Template panel on the right, open the dropdown and select faqs.

Step 5: Set the page visibility as required and click Save.

Open FAQs in the Theme Editor

✓

Step 1: Go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Use the page/template selector at the top of the Theme Editor and open the faqs page.

Step 4: In the left sidebar, select any Collapsible content section to edit that FAQ group.

Step 5: Expand the section in the sidebar to view its existing Collapsible row blocks or add new rows.

Collapsible Content Section

Each Collapsible content section acts as a separate FAQ group. For example, one section can contain product questions while another can contain shipping questions. Select a section itself to change its section-level settings.

  • Preheading: Add optional text above the main section heading.
  • Subheading / heading content: Set the visible group title, such as Products or Shipping.
  • Heading tag: Choose the HTML heading level used by the section.
  • Heading alignment: Align the heading left, center, or right.
  • Colors: Control the section text, background, and related color options.
  • Section margin and padding: Adjust spacing around and inside the section.
  • Custom attributes / Custom CSS: Add a custom ID, custom classes, or section-specific CSS when needed.

Add Collapsible Rows

You can add more questions inside each Collapsible content section.

✓

Step 1: In the left sidebar, expand the Collapsible content section you want to edit.

Step 2: Click Add Collapsible row.

Step 3: A new Collapsible row is added inside that specific FAQ group.

Step 4: Repeat this for every additional question you want to add.

Each Collapsible content section has its own rows. This lets you keep separate groups such as Products, Shipping, Returns, Orders, or other FAQ categories.

Edit Each FAQ Row Separately

Click an individual Collapsible row in the left sidebar to edit that question and answer independently from the other rows.

  • Heading: Enter the FAQ question shown in the collapsed row.
  • Collapsible row: Enter and format the answer in the rich-text editor.
  • Remove block: Delete only the selected FAQ row without removing the entire Collapsible content section.

Add More Sections to the FAQs Page

You can also click Add section in the left sidebar to add other supported theme sections to the FAQs page. This is useful when you want to place banners, icons, promotional content, or other sections above or below the FAQ groups.
