Onepix Shopify Theme
Collection Pages

Default Collection

The Default Collection template controls the standard collection page layout in the Onepix theme. The main Product grid section lets you configure the number of products, responsive columns, product-card appearance, filtering and sorting controls, spacing, and custom attributes.

How to Apply This Collection Template

Before customizing the Default Collection layout in the Theme Editor, assign its collection template to the collection you want to use.

✓

Step 1: From your Shopify Admin, go to Products → Collections.

Step 2: Create a new collection or open an existing collection, then add the products you want to show in that collection.

Step 3: Scroll down on the collection page until you find the Theme template option.

Step 4: Open the Theme template dropdown and select Default collection.

Step 5: Click Save to apply the selected collection template.

The same process is used for all Onepix collection templates. Choose the required template from the dropdown, save the collection, and then open that template in the Theme Editor to customize its Product grid and any additional sections.

How to Open the Default Collection Template

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: From the template selector at the top, open Collections.

Step 4: Select Default collection.

Step 5: Click Product grid in the left sidebar to edit the collection layout.

Product Grid Settings

The upper part of the Product grid settings controls the collection layout, product count, responsive columns, pagination, product-card styling, and filtering behavior.

  • Layout: Choose the overall section width, such as Container.
  • Products per page: Set how many products are displayed before pagination or loading more products.
  • Columns desktop: Set the number of product columns on desktop.
  • Columns tablet: Set the number of product columns on tablet.
  • Columns mobile: Set the number of product columns on mobile.
  • Gutter: Control the spacing between product cards.
  • Pagination: Choose the collection pagination behavior, such as Click to load.
  • Image ratio: Set the product-card image aspect ratio.
  • Quick add: Show or hide quick-add functionality on product cards.
  • Show border: Enable or disable a border around product cards.
  • Border color: Set the product-card border color.
  • Border radius: Adjust the corner radius of the product cards.
  • Border width: Control the border thickness.
  • Border style: Choose the border style, such as Solid.
  • Enable collections list: Show or hide the collection-list selector.
  • Collections list: Choose which collections can appear in the collection-list control.
  • Filters: Enable collection filtering. Custom filters can be managed with Shopify Search & Discovery.
  • Filter layout: Choose the filter presentation, such as Vertical.
  • Sorting: Show or hide collection sorting.
  • Open all dropdowns: Keep the filter groups expanded when using a vertical or drawer filter layout.

Spacing and Custom Settings

The lower settings area lets you control section spacing and add custom identifiers or CSS hooks.

  • Top margin: Adjust the outer spacing above the Product grid section.
  • Bottom margin: Adjust the outer spacing below the section.
  • Top padding: Adjust the inner spacing above the collection content.
  • Bottom padding: Adjust the inner spacing below the collection content.
  • Custom ID: Add a custom HTML ID to the section.
  • Custom classes: Add one or more custom CSS class names.
  • Theme Settings: Open theme-level settings related to the section when required.
  • Custom CSS: Add CSS that applies only to this Product grid section.

Adding More Sections to a Collection Page

The collection template is not limited to the Product grid. You can also add other theme sections to the collection page.

In the left sidebar, click Add section below the template content, then choose the section you want to add. This lets you place additional promotional, content, or merchandising sections on the collection page alongside the Product grid.
