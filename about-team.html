About Team

The About Team section is used to present your team members in a grid layout on the About page. You can control the section heading, responsive column layout, colors, spacing, and also add multiple Team member blocks from the left sidebar.

How to Add About Team

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the About page template in the Theme Editor.

Step 4: Click Add section and choose About Team, or select the existing section from the left sidebar.

Step 5: Use Add Team member to create more team cards, then edit each member separately.

Section Settings

The screenshot below shows the section-level settings available for About Team.

  • Heading: Edit the main section title.
  • Heading tag: Choose the heading tag, such as H2 or H3.
  • Columns desktop: Set how many team cards appear per row on desktop.
  • Columns tablet: Set the number of team cards shown on tablet.
  • Columns mobile: Choose between 1 column or 2 columns on mobile.
  • Background color: Set the section background color.
  • Heading text color: Set the color of the section heading.
  • Name card background: Control the background color of the member name card.
  • Image title color: Set the color used for the member name/title text.
  • Description color: Set the color used for the member description or role text.
  • Padding top: Adjust the inner top spacing.
  • Padding bottom: Adjust the inner bottom spacing.
  • Custom ID: Add a custom HTML ID.
  • Custom class: Add a custom CSS class name.
  • Custom CSS: Add section-specific CSS if needed.
  • Remove section: Remove the section if you no longer need it.

Adding Team Members

From the left sidebar, click Add Team member to add a new person to the section. Each team member can then be edited separately from its own block settings in the Theme Editor.

  • Add Team member: Adds a new member card to the section.
  • Team member blocks: Each member appears as its own editable block in the left panel.
  • Separate editing: You can update each member individually without affecting the others.
