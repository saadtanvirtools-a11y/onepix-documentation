Homepage Sections

Content Block 1

The Content Block 1 section is a flexible homepage content section used to highlight a hero product or featured message. It allows you to combine a main image, heading, descriptive text, icon-based content points, and a button-style layout to create a clean promotional block.

How to Add Content Block 1

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the Home page template in the Theme Editor.

Step 4: Click Add section and select Content Block 1.

Step 5: Configure the section settings and then use Add block from the left panel to add and manage content blocks separately.

Section Settings

Select the Content Block 1 section in the left panel to manage the main layout and style settings.

  • Layout: Choose the section width layout, such as Container.
  • Style layout: Select the visual style layout option for the section.
  • Image: Upload the main product or feature image.
  • Image link: Add a link to the main image.
  • Show image on right side: Move the image to the right side of the section when enabled.
  • Image width: Set the image width, such as 40%, 50%, or 60%.
  • Text vertical position: Align the content vertically as Top, Middle, or Bottom.
  • Desktop text alignment: Choose left, center, or right alignment for desktop.
  • Mobile text alignment: Choose left, center, or right alignment for mobile.
  • Enable controls: Turn this option on if the section supports additional interactive controls.
  • Use custom colors: Enable custom section colors.
  • Text color: Set the text color for the section content.
  • Background color: Set the background color of the section.
  • Background gradient: Add a background gradient if needed.
  • Margin top: Adjust the outer top spacing.
  • Margin bottom: Adjust the outer bottom spacing.
  • Padding top: Adjust the inner top spacing.
  • Padding bottom: Adjust the inner bottom spacing.
  • Custom ID: Add a custom HTML ID for the section.
  • Custom class: Add a custom CSS class name.
  • Custom CSS: Add custom CSS specifically for this section.

Adding Blocks

In this section, you can also click Add block from the left sidebar and then edit each block separately. This makes Content Block 1 flexible because the heading, text, and icon content can all be managed independently.

You can build the whole section step by step by adding blocks and editing them one by one from the left sidebar.

Heading Block

The Heading block controls the main heading text displayed inside the section.

  • Heading: Add or edit the heading text.
  • Heading tag: Choose the HTML tag, such as H2, H3, or H4.
  • Heading size: Choose the heading size, such as Large, Medium, or Small.
  • Margin top: Control the spacing above the heading block.
  • Remove block: Delete the heading block if not needed.

Text Block

The Text block is used for the main paragraph or descriptive content inside this section.

  • Text: Add or edit the paragraph content.
  • Margin top: Control the spacing above the text block.
  • Remove block: Delete the text block if required.

Icon with Text Block

The Icon with text block lets you add multiple content points, each with its own image, heading, and subheading. As shown in your screenshot, this block can be edited separately from the left panel.

  • Margin top: Control the spacing above the block.
  • Image 1 / Image 2 / Image 3: Upload an image or icon for each content item.
  • Heading 1 / Heading 2 / Heading 3: Add the title for each item.
  • Subheading 1 / Subheading 2 / Subheading 3: Add supporting text for each item.
  • Remove block: Delete the icon-with-text block if not needed.
