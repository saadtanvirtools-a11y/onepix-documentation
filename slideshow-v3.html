Slideshow V3

The Slideshow V3 section is the main hero slider for the Onepix homepage. It lets you create multiple image slides with headings, supporting text, buttons, links, optional product selection, and custom slide colors.

How to Add Slideshow V3

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the Home page template in the Theme Editor.

Step 4: Click Add section and select Slideshow v3.

Step 5: Inside the section, click Add Image slide to add another slide.

Image Slide Settings

Each Image slide block has its own content and design settings. Select a slide in the left panel of the Theme Editor to edit the following options.

  • Image: Select the main image displayed on the slide.
  • Preheading: Add the small text displayed above the main heading.
  • Heading: Enter the primary title for the slide.
  • Heading size: Choose the display size of the slide heading.
  • Subheading: Add supporting text below the heading using the rich-text field.
  • Button label: Set the text shown inside the call-to-action button.
  • Link: Choose where the button sends the customer.
  • Button style: Select the visual style used for the slide button.
  • Product: Optionally select a product for the slide.
  • Use custom colors: Enable this option to use slide-specific colors.
  • Text: Set the slide text color when custom colors are enabled.
  • Background: Set the slide background color.
  • Background gradient: Optionally apply a gradient background.
  • Background shape: Set the color used for the decorative background shape.

Adding Multiple Slides

Use Add Image slide inside Slideshow v3 to create more slides. Each slide can have its own image, text, button destination, product selection, and color settings. Customers can move between slides using the slideshow navigation controls shown on the storefront.

Keep the main heading and call-to-action concise so the hero content remains easy to read across desktop, tablet, and mobile layouts.
