Onepix Shopify Theme
Theme Settings

Global

The Global settings control layout options that apply across the Onepix storefront. The Page width setting lets you control the maximum width of the main page content.

How to Set the Page Width

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: In the Theme Editor, open Theme settings.

Step 4: Open Global.

Step 5: Adjust the Page width slider or enter the required value in pixels.

Page Width

Use Page width to set the maximum width of the main content area across the theme. Move the slider to change the value, or enter the pixel value directly in the field. The screenshot below shows 1100 px as an example setting.
