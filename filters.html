Onepix Shopify Theme
Store Features

Filters

Use Shopify's Search & Discovery app to create and manage storefront filters. These filters appear on supported collection layouts in the Onepix theme, such as Filter Drawer, Horizontal Filter, Sidebar Filter, and other filter-enabled collection pages.

Open Filters in Shopify Admin

✓

Step 1: From Shopify Admin, open the Search & Discovery app.

Step 2: Click Filters in the left sidebar.

Step 3: Review your existing filters such as Availability, Price, Color, Category, Product type, and other supported sources.

Step 4: Click Add filter to create a new filter.

Add a New Filter

✓

Step 1: On the Add filter screen, click Select source.

Step 2: Choose the filter source you want to use. This can be a standard source, a product option, or a category metafield.

Step 3: Enter the Filter label customers should see on the storefront.

Step 4: Select the values you want to make available for that filter.

Step 5: Click Save to publish the filter.

How Filters Work in Onepix

  • Filter source: Determines what product data powers the filter.
  • Filter label: Controls the filter title customers see on collection pages.
  • Values: Lets you choose which options will be available in the storefront filter.
  • Supported layouts: Filters can be used with Onepix collection templates that have filtering enabled.
  • Live updates: Any filter changes saved in Search & Discovery are reflected on the storefront after the theme settings and collection template support are in place.
After adding filters in Search & Discovery, make sure the relevant Onepix collection page layout has filtering enabled so customers can see and use the filters on the storefront.
