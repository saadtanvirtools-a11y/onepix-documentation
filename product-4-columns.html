Collection Pages

Product 4 Columns

The Product 4 Columns collection template displays four product cards per row on desktop. It uses the standard Product grid settings, horizontal filtering, sorting controls, and the same configurable product-card styling available on the other collection templates.

How to Apply This Collection Template

Before customizing the Product 4 Columns layout in the Theme Editor, assign its collection template to the collection you want to use.

✓

Step 1: From your Shopify Admin, go to Products → Collections.

Step 2: Create a new collection or open an existing collection, then add the products you want to show in that collection.

Step 3: Scroll down on the collection page until you find the Theme template option.

Step 4: Open the Theme template dropdown and select product-4-columns.

Step 5: Click Save to apply the selected collection template.

The same process is used for all Onepix collection templates. Choose the required template from the dropdown, save the collection, and then open that template in the Theme Editor to customize its Product grid and any additional sections.

How to Open the Product 4 Columns Template

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the collection template selector and choose product-4-columns.

Step 4: Select Product grid from the left sidebar.

Step 5: Set Columns desktop to 4. The screenshots show 3 columns on tablet and 2 columns on mobile.

4-Column Desktop Layout

The defining setting for this template is Columns desktop = 4. This places four product cards across the desktop product grid while keeping the responsive tablet and mobile column controls separate.

If you change Columns desktop away from 4, the template will no longer display the four-column desktop layout shown in the screenshots.

Product Grid Settings

Select Product grid to configure the collection grid and its responsive layout.

  • Layout: Choose the section width option, such as Container.
  • Products per page: Set how many products appear before pagination or loading more products.
  • Columns desktop: Set this to 4 for the four-column layout.
  • Columns tablet: Set the tablet grid independently; the screenshot shows 3.
  • Columns mobile: Set the mobile grid independently; the screenshot shows 2.
  • Gutter: Adjust spacing between product cards.
  • Pagination: Choose the loading method, such as Click to load.

Product Card Settings

  • Image ratio: Control the product-card image aspect ratio.
  • Quick add: Enable or disable quick purchasing controls.
  • Show border: Show or hide the product-card border.
  • Border color: Set the product-card border color.
  • Border radius: Adjust the product-card corner radius.
  • Border width: Control the border thickness.
  • Border style: Choose the border style, such as Solid.

Filtering and Sorting

  • Enable collections list: Show or hide the collection-list control.
  • Collections list: Choose collections to expose through the collection-list setting.
  • Filters: Enable storefront product filtering. Filter options are configured through Shopify Search & Discovery.
  • Filter layout: The screenshots show Horizontal, placing filter dropdowns above the four-column grid.
  • Sorting: Enable or disable collection sorting.

Spacing and Custom Settings

  • Margin top: Adjust the outer spacing above the Product grid section.
  • Margin bottom: Adjust the outer spacing below the section.
  • Padding top: Adjust the inner top spacing.
  • Padding bottom: Adjust the inner bottom spacing.
  • Custom ID: Add a custom HTML ID to the section.
  • Custom classes: Add custom CSS classes when needed.
  • Theme Settings: Open shared theme-level settings when required.
  • Custom CSS: Add CSS that applies only to this Product grid section.

Add More Sections

You can also add additional theme sections to the product-4-columns collection template. Click Add section in the left sidebar and choose any supported section you want to place above or below the Product grid.
