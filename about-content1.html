About Page

About Content 1

The About Content 1 section is a two-column about-page section used to combine a feature image with brand messaging. It lets you show a preheading, two separate heading areas, descriptive paragraph text, alignment controls, and full color and spacing settings.

How to Add About Content 1

✓

Step 1: From your Shopify Admin, go to Online Store → Themes.

Step 2: Find the Onepix theme and click Customize.

Step 3: Open the About page template in the Theme Editor.

Step 4: Select About Content 1 from the left sidebar.

Step 5: Edit the content, image, typography, alignment, color, and spacing settings from the right panel.

Main Settings

The screenshot below shows the main editable controls available for the About Content 1 section.

  • Preheading: Add or change the small top label text.
  • Top heading: Edit the first large heading area.
  • Top heading HTML tag: Choose the semantic heading tag such as H1, H2, H3, or H4.
  • Top heading size: Set the size of the first heading.
  • Image: Upload or replace the feature image shown in the section.
  • Second heading: Edit the second heading area displayed below the preheading.
  • Second heading HTML tag: Choose the semantic tag for the second heading.
  • Second heading size: Control the display size of the second heading.
  • Paragraph: Update the descriptive paragraph text.
  • Desktop text alignment: Set left, center, or right alignment for desktop.
  • Mobile text alignment: Set left, center, or right alignment for mobile devices.

Color & Spacing

You can also control the section styling with these design settings.

  • Use custom colors: Enable custom colors for this section.
  • Label color: Set the color of the preheading text.
  • Heading color: Set the color of the main heading text.
  • Text color: Set the paragraph text color.
  • Background color: Set the background color of the section.
  • Background gradient: Apply a gradient background if needed.
  • Margin top: Adjust the outer top spacing.
  • Margin bottom: Adjust the outer bottom spacing.
  • Padding top: Adjust the inner top spacing.
  • Padding bottom: Adjust the inner bottom spacing.
  • Custom ID: Add a custom HTML ID.
  • Custom class: Add a custom CSS class name.
  • Custom CSS: Add section-specific custom CSS.
  • Remove section: Remove the section if it is no longer needed.
